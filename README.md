# Phishing URL Detection Using Machine Learning

## 📌 Project Overview

This project uses Machine Learning to identify potentially phishing URLs and distinguish them from legitimate URLs. Phishing is a cyberattack in which attackers create fake websites or links to steal sensitive information such as passwords and personal details.

The model analyzes URL-related data and predicts whether a URL is **Phishing** or **Legitimate** based on the dataset used for training.

## 🎯 Objectives

- Detect phishing URLs using Machine Learning.
- Classify URLs into phishing and legitimate categories.
- Evaluate model performance using standard classification metrics.
- Demonstrate how Machine Learning can help improve cybersecurity.

## ⚙️ Project Workflow

1. Import the required Python libraries.
2. Load the phishing URL dataset.
3. Clean and preprocess the data.
4. Split the dataset into training and testing sets.
5. Train the Machine Learning model.
6. Predict the results using test data.
7. Evaluate the model using accuracy, precision, recall, and F1-score.

## 📊 Model Evaluation

The model is evaluated using the following metrics:

- **Accuracy:** Measures the overall proportion of correct predictions.
- **Precision:** Measures how many URLs predicted as phishing are actually phishing.
- **Recall:** Measures how many actual phishing URLs are correctly detected.
- **F1-score:** Combines precision and recall into a single metric.
